# Website typography

Manrope variable (normal, weights200–800) and Instrument Serif italic400.
Latin WOFF2 subsets obtained from Google's official Fonts CSS response; no runtime
CDN request is used. Each font's SIL Open Font License is included unchanged.

Official upstream licensing:
- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/instrumentserif

Font files:
- https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- https://fonts.gstatic.com/s/instrumentserif/v5/jizHRFtNs2ka5fXjeivQ4LroWlx-6zAjjH7M.woff2

Only the marketing/setup website uses these fonts. Generated presentation and
infographic objects retain their existing engine font contracts.
