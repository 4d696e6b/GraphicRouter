THE PROJECT WORKFLOW

From your facts
to your pitch.

How to use GraphicRouter when it is available in your account. This page shows prepared examples; it does not run the plugin.

01

Supply your facts

Describe your topic, audience and intended outcome. Provide the evidence you have; missing evidence stays a question or placeholder.

02

Plan five slide roles

Build a hook/problem, product answer, workflow, proof and next step. Each slide has a headline, one takeaway and up to three content blocks.

03

Inspect the construction

Review layout boxes, content placement and the finished composition. Preview and PowerPoint export use the same visual blueprint.

04

Direct a precise change

Revise text, speaker notes, an element colour, the deck accent or an allowed layout. Previous versions remain unchanged; layout changes must fit the existing content.

05

Prepare your presentation

Export PowerPoint with three-minute core and five-minute expanded speaker notes. Keep the PowerPoint for manual Canva upload if needed; review imported objects and fonts.

VERSION ONE

The presentation basics.

Five slides, one story

Exactly five 16:9 slides, using hero, cards, comparison, process and closing recipes.

A consistent visual system

Arial, an off-white/dark/violet theme and a configurable accent. Slides use native text, simple shapes, lines and bundled images.

Facts stay in your hands

ChatGPT supplies structured story content. A deterministic renderer composes the elements; no additional model service writes the presentation.

THE BASICS

A few things
worth knowing.

What does GraphicRouter do?+

It helps shape supplied facts into exactly five 16:9 slides, with speaker notes and focused revisions. The examples on this website are prepared assets, not a live plugin session.

Where can I install or use it?+

GraphicRouter is being developed for ChatGPT. No official downloadable package or verified public connection link is available yet. Hosted tools/widget and account access still need verification; installation instructions will follow the actual release.

Do I need Canva?+

PowerPoint and speaker notes provide a handoff without Canva. You can upload the PowerPoint manually. Application Canva OAuth/import remains unverified; a separate manual fixture import confirmed text and image editing only.

What are the current limitations?+

Version one focuses on five slides and supported revisions. Arbitrary deck import/editing, freeform placement, image generation, animation, two-way Canva sync and marketplace publication are outside scope. Each Canva import creates a new design version. Shape, line and font conversion still need editor checks.
