Before you get started

Where can I use GraphicRouter?+

GraphicRouter is being developed for ChatGPT. No official download or verified public connection link is available yet; hosted tools and account access still need verification.

Do I need Canva?+

No. PowerPoint and speaker notes provide the handoff. Manual Canva upload is a fallback. A separate manual import confirmed text and image editing; application OAuth/import and shape, line and font checks remain pending. Canva edits do not sync back.

What can the current version create?+

The locally verified workflow creates five 16:9 slides with speaker notes and supports focused text, colour, notes and allowed layout changes. Arbitrary deck import, freeform placement, image generation and animation are outside v1 scope.
