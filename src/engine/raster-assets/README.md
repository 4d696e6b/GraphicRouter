# Inspection fonts

Liberation Sans Regular and Bold, distributed under the accompanying SIL Open
Font License 1.1. Upstream: https://github.com/liberationfonts/liberation-fonts .
These fonts are bundled only for offline image inspection as Arial-compatible
substitutes. No proprietary system font software is redistributed. The stored
blueprint, SVG preview and PowerPoint continue to name Arial; exact Canva font
rendering requires inspection of the imported result.
