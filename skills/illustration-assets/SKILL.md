# Illustration and asset composition

Choose imagery by explanatory purpose: a gesture, location, mechanism, object, relationship or evidence. Establish one visual language across a project. Decorative icons are optional; they must not masquerade as an instructional demonstration or scientific diagram.
compose_component provides text-free native geometric icons such as check, arrow-right, target, clock, person, document and steps. These remain editable shapes/lines. They are intentionally simple; do not promise detailed hands, anatomy, maps or arbitrary vector illustrations from this library. The current exporter accepts only registered PNG/JPEG assets; it has no arbitrary remote upload or custom-font ingestion. Never invent asset IDs.
For richer imagery, preserve the user's selected route and use accessible Canva source assets or supported connected asset tools. Inspect the actual asset, relevant rights/usage information, cropping and text content before use. Record source/rights as known, unknown or user supplied; do not label unknown licensing cleared. Avoid extra generation credits without the user's existing authorization. Do not automatically regenerate failed drafts.
Every heading, number, label and caption stays native text. Illustrations/backgrounds must be text-free. Image lettering cannot be repaired by covering it and adding another text box. A selected image being movable is not evidence that its letters are editable. Replace/rebuild a contaminated section with clean assets and native text, then inspect again. Asset accessibility text should describe its informative purpose. Read quality-review and use review_canva_design on the actual supplied Canva snapshot.
