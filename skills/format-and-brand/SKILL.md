# Format adaptation and brand consistency

Inspect the source content and visual system before adapting it. Preserve exact figures, units, qualifications, source links and mandatory wording. Reuse approved vocabulary and colour roles; distinguish must-keep brand rules from optional references. Do not claim to have inspected an inaccessible source.
Adaptation is recomposition, not uniform scaling. A poster may explain spatial relationships, a slide needs one stage-readable message, and a carousel needs useful progression. Change information grouping, density, line breaks and reading order for the new medium. Keep excluded or expanded detail in notes or an explicitly requested appendix; do not silently discard facts or legal text.
Native adaptation creates a new canvas/document from inspected source material with stable semantic element names within the new result. It does not mutate the original, provide a lossless arbitrary import converter or synchronize manual Canva changes back. Canvas dimensions are 320–4000 per side and document pages share one size; source glyph/font/asset constraints still apply. A required unsupported font/language/logo must be resolved with a supported connected Canva route or disclosed before promising delivery.
Record a compact content map: source claim → target page/element → supporting source, plus any intentional editorial change. Review completeness as well as appearance. Apply the same visual system across target outputs but allow layout variety. Inspect representative reading sizes and all final native text/Canva layers. Read art-direction, the relevant format skill, and quality-review.
This new-format adaptation guidance does not override a user request to edit the original Canva file. Use plan_canva_edit in edit_original mode for that request, skip new-design intake and preserve the actual design ID/link.
