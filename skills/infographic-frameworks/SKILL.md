# Infographic frameworks

Select structure from the relationship in the supplied content, not the subject's keyword or a favourite template. Process shows actions and their order; comparison aligns the same criteria on a common scale; timeline requires real dates/order; hierarchy shows parent-child relationships; annotation connects a label to a meaningful location; statistical story explains a supported finding. Geographic claims need actual geographic evidence and assets; do not fabricate a map from decorative blobs.
Plan one focal message and a reading path. State why the structure suits the audience in one or two public sentences. Use information-bearing geometry: aligned comparison axes, numbered steps, connectors and useful grouping. Do not make every concept an identical card or force an unrelated icon into an instructional illustration. A handwashing action requires a recognisable gesture; a circle marked with a number alone does not explain it.
For quick work, choose one suitable direction. Balanced work can compare two small structure studies. Detailed work may compare up to three when there is a meaningful tradeoff. Preserve the user's chosen Canva/source/native route. Blank native work uses create_canvas and edit_canvas; multi-page work uses create_document and edit_document. Inspect the rendered page and critical detail crops before export; apply only useful refinements. Use compose_component for supported numeric charts and geometric icons, not a substitute for detailed illustration. Read quality-review before final delivery.
